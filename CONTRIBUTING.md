# Contributing to Inrface

Thanks for looking. Here is what helps right now.

## Ideas and bug reports

Open an issue. For a bug, say what you did, what you expected and what happened, and include the relevant lines from `docker compose logs app` with anything private removed.

## Code

Inrface isn't taking code from outside yet, so a pull request from a fork will be closed without being merged.

The reason is ownership. Inrface is released under the AGPL, and there are plans for a hosted version and paid add-ons next to it. That only works while the project holds the rights to all of its code. Before outside code can go in, there has to be a contributor agreement that gives the project those rights, and it hasn't been written.

Until then, the best way to get a change made is to describe it in an issue.

## Using and changing your own copy

None of this limits what you do with your own copy. The [license](LICENSE) lets you run it, change it and share your version, as long as people who use your version over a network can get its source under the same license.
